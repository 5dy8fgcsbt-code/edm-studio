# 碰撞模型

0.9.2 支持直接打开 EDM v8/v10 的 `ShellNode` 三角碰撞壳体，例如 `FA-18C_Collision.edm`。用“打开 EDM”或拖放文件即可，无需勾选额外模式。

文件没有外观三角网格时，程序自动显示碰撞壳体，信息面板标明“碰撞模型”。壳体采用柔和的区分颜色和双面显示；下方“线框”可用于查看三角结构。左侧参数滑块、播放、复位与动画部件识别照常使用，壳体跟随原父节点运动和显隐。

右侧“导出”可选择：

- **GLB / glTF / FBX**：保存壳体网格、层级和所选参数动画。
- **OBJ**：保存当前姿态的静态壳体网格及颜色材质。

碰撞壳体的顶点格式直接来自每个 ShellNode，不依赖外观材质。缺少法线时由三角形计算；壳体名称、属性和来源标记随元数据保留。导出的颜色用于区分结构。

这些碰撞表面不提供涂装 UV，软件不会为它们生成可绘制贴图；直接画笔、贴花和相机投影在纯碰撞模型上不启用，涂装扫描与预览贴图加载也会跳过。

如果 EDM 同时有外观三角网格和内部碰撞壳，仍按外观模型显示和导出，不把碰撞壳叠到机身表面。本次支持 ShellNode 的三角壳体；SegmentsNode 碰撞线段尚不转换为通用几何。
