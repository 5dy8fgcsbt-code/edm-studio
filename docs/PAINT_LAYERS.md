# 涂装图层

0.10.0 在右侧 **绘制 → 涂装图层** 中管理图层。一套图层覆盖整架模型及其外挂，不需要拾取材质。列表上方的层覆盖下方的层，底图保留首次绘制时载入的外观。

## 开始绘制

1. 打开 EDM，选择需要的基础涂装，再进入右侧「绘制」。
2. 选中「图层 1」，或点击「+ 新建图层」，输入名称，例如「机身色块」。
3. 选择「直接画笔」，在模型表面按住左键绘制。笔迹自动写入落点所对应贴图的选中层，跨过 UV 接缝或其他材质也无需手动切换。
4. 为图片另建一层，例如「机徽」。选择「贴花」并加载透明 PNG，在模型上移动鼠标预览，左键盖印；相机投影也写入当前层。
5. 点击「保存工程与 DCS 涂装…」。生成的 `project.edmpaint.json` 用于继续编辑，`description.lua` 和 DDS 是可见图层合成后的 DCS 涂装。

建议为不同色块、不同贴花分别新建图层，方便单独隐藏、调整不透明度或删除。当前是像素图层：贴花盖印后保存在图层像素中，大小、位置与旋转须在盖印前调整；它不是可再次拖动的独立投影对象。需要重新放置时可撤销盖印，或清空专用图层后重新盖印。

## 图层面板

| 控件 | 作用 |
| --- | --- |
| 名称行 | 选择画笔、贴花、模板和投影的目标层 |
| 名称左侧复选框 | 显示或隐藏这一层，隐藏内容仍保存在工程中 |
| 名称输入框 | 重命名，回车或结束编辑后生效 |
| 图层不透明度 | 调整这一层所有内容的强度，松开滑块后更新模型 |
| 保持底图透明遮罩 | 保留下面图像的 Alpha；关闭后按图层覆盖率正常合成 Alpha |
| 上移 / 下移 | 改变覆盖顺序 |
| 复制图层 | 创建独立副本，之后修改互不影响 |
| 删除图层 | 删除选中层；至少保留一个可编辑层 |
| 清空当前图层 | 移除该层在所有已编辑贴图上的内容，底图和其他层保留 |
| 撤销 / 重做整次操作 | 一整笔、一次盖印、一次模板应用或一次图层调整为一步 |

当前层隐藏或不透明度为 0 时不能落笔，先显示它或选择其他层。画面下方「浏览已编辑的涂装」用于整套原图/合成图对照，与逐层显示开关独立。

## 模板与外挂

「将模板载入当前图层…」支持平面 PNG、DDS、TGA、JPG 等图片。载入后下一次在模型落笔会自动定位贴图，将模板缩放到该画布尺寸，并替换这个贴图的当前层。它不会替换底图或其他层，整步可撤销；取消笔画会恢复原内容并保留待用模板。PSD 的图层结构不导入，请在原编辑器导出平面图片。

同一层可同时绘制飞机、挂架和武器。隐藏外挂后，它不参与落笔拾取或图片投射遮挡；已有图层内容保留。卸载外挂时，仍保留其他物体的图层和撤销记录；被卸载物体有绘制时，恢复副本包含完整分层数据。

## 保存、兼容与性能

新版工程格式为 v3，保存原始底图、每层像素、名称、覆盖顺序、显示状态、不透明度、透明遮罩设置和当前层。打开旧 v2 工程时，原来的平面绘制结果作为底图保留，新增编辑写入新图层；旧文件不会被覆盖。撤销历史仅在当前会话中保留。

DCS 涂装及 GLB / glTF / OBJ / FBX 导出使用可见层的最终合成图。隐藏层不会出现在导出图像中，但仍完整保存在绘制工程里。

每个工程最多 64 层。空图层不分配整张贴图，笔迹按 64×64 像素小块保存，复制层在首次修改时才复制相应块。GPU 仍只接收每张贴图的一份合成结果，相机移动不会重新合成图层。贴图编辑总预算为 2 GiB，独立于涂装预览显存预算；画布使用首次触及时的 2048 / 4096 / 8192 分辨率，已编辑画布不会随预览质量改变而重新采样。
