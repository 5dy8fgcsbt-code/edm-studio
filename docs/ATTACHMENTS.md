# 挂点、外挂与涂装

## 连接模型

1. 打开飞机 EDM，勾选画面下方的 **显示挂点**。
2. 悬停圆点查看名称，点击目标 `Pylon`，在文件窗口选择挂架或武器 EDM。
3. 程序将外挂的 `AttachPoint` 与目标连接点的位置、方向对齐。挂架上的 `Point01`、`Point02`、`Point03` 使用同一操作，可继续连接武器。

蓝色圆点表示 Pylon / Point，橙色表示已有外挂，灰色表示其他 Connector。标记可透过模型查看，随节点动画移动。界面按节点索引选择，因此不同挂架可以具有相同的 Point 名称。

连接按外挂默认姿态中的 AttachPoint 计算，保留完整仿射变换、原有动画与蒙皮，并跟随父挂点运动。每件外挂使用独立的内部动画参数编号，避免与飞机或另一件武器的同号参数相互影响。原参数与内部编号的对应关系保留在导出元数据中。

没有 AttachPoint 时按模型原点连接，并在状态栏和日志中提示；多个自身 AttachPoint 会明确报错。该功能允许手动连接任意 EDM，未读取飞机允许武器列表来限制选择。

## 卸载外挂

点击黄色（橙色）的已挂载连接点，旁边会出现带挂点名称的菜单。按 **卸载** 才移除物体；点击空白处或按 Esc 可以收起菜单，点选本身不会卸载。

在飞机的 Pylon 卸载挂架时，它下面的武器也会一起移除；在挂架的 Point 卸载武器时，挂架及其他武器保留。卸载会移除相应网格、贴图绑定和动画参数，后续绘制、遮挡、保存、模型与涂装导出均不再包含这些物体。剩余物体的绘制内容、画笔撤销记录和当前动画姿态保留。

被卸载物体有绘制画布时，程序先在 EXE 旁的 `PaintRecovery/EDM-Recovery-*` 保存绘制恢复工程。需要找回时，打开原主机 EDM，再通过绘制面板打开其中的 `project.edmpaint.json`；会恢复卸载前的组合和画布。源 EDM 与原涂装仍需可读取。卸载本身不属于画笔的撤销步骤。

## 绘制和显示

在右侧 **绘制** 中使用直接画笔、贴花或相机投影，机体和外挂的命中位置都会自动映射到各自贴图。模板仍在落笔时绑定到命中的材质。绘制时可以取消 **显示挂点**，使圆点不再占用鼠标点击。

取消 **显示外挂物体** 后，所有外挂同时退出渲染、绘制拾取与投影遮挡；可以直接画到原先被外挂挡住的机体。重新显示后，外挂及其绘制内容恢复。正在执行笔划或投影时，开关会暂时禁用，等待当前操作完成。

**浏览已编辑的涂装** 同时控制机体和外挂的原图对照。添加外挂、切换可见性均保留已有画布和撤销记录。

保存绘制工程会记录挂接顺序、连接点、参数映射和源 EDM 路径。以后先打开主机 EDM，再打开工程，即可恢复整个组合及绘制内容。源 EDM 需仍在记录的路径；工程中的 DDS 和涂装配置会独立保存。

## 导出

GLB / glTF / FBX 导出整个挂接层级与动画；OBJ 导出组合的当前静态姿态。**显示外挂物体** 是预览开关，导出始终包含已连接的外挂。

启用 **导出贴图与当前涂装** 时，组合导出还会在模型旁生成独立的 `EDM-Livery-*` 目录，内含：

- 一份 `description.lua`，汇总机体、挂架、武器的材质贴图映射及当前涂装配置。
- 原始 DDS 依赖（保留压缩和 mip）、RoughMet、动态编号所需贴图，以及编辑后的 DDS。
- `project.edmpaint.json`，保存挂接关系、参数映射、来源及已求值 Lua 配置；有绘制时还保存可恢复的 PNG 画布。

导出完成后的状态栏和 `.report.json` 会给出 description.lua 路径。关闭导出贴图时不生成这份涂装目录。动态 Lua 在导出前求值，生成的 description.lua 是该配置的当前结果。

DCS 的 description.lua 按材质名称寻址。如果两件物体使用相同材质名称但需要不同贴图，单份配置无法区分它们。程序会明确指出冲突并停止导出，避免覆盖；相同内容可以共享。重复挂载同一种武器后分别绘制，也可能遇到这一限制。

## CLI

`--attach` 可以重复使用，按给定顺序逐级挂接。名称重复时可以使用 `#节点索引`；通过 `inspect --dump-world` 查看索引。

```powershell
./edm-native-cli.exe export 'aircraft.edm' --attach 'Pylon2=lau-88.edm' --attach 'Point01=agm-65d.edm' --output 'loadout.fbx' --args 0,9,10,38
./edm-native-cli.exe inspect 'aircraft.edm' --attach 'Pylon2=lau-88.edm' --hide-attachments --dump-world 'hidden.json'
```

GUI 启动也支持重复 `--attach`，以及 `--show-connectors`、`--hide-attachments`。原始 DCS 飞行、武器性能和任务挂载规则不属于涂装 description.lua；本功能保存模型组合与外观。
