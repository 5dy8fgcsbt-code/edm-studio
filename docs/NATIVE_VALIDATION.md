## 0.8.1 F-15E 不透明材质

## 调试中解决的问题

- Lua C 库的 longjmp 跨过 C++ include 回调对象，导致错误 require() 访问越界。Lua 改以官方支持的 C++ 模式编译，使用异常展开；回调不吞 Lua 内部异常。
- 原测试只确认配置失败，可能把子进程崩溃当作通过。现检查进程退出码和结构化 Lua 错误，另外覆盖 pcall(require)、深层表和递归栈容量。
- 本机 LLDB 缺少 liblldb.dll，停用该工具。开发调试器只依赖 Windows SDK，不纳入软件发行包。
- GPU 实例索引、镜像三角面、PNG 编码格式、纹理预算分配、异步取消旧任务与 COM 初始化配对均已修正并验证。
