# 曲面贴花（0.12.1）

用于把徽标、图案沿机身等曲面贴上去，自动写入对应贴图的当前涂装图层。无需在模型上先选材质。

## 操作

1. 打开 EDM，在右侧进入「绘制」，选择「贴花」。
2. 在「涂装图层」中选择可见且不透明度大于零的图层；建议为新贴花建立单独图层。
3. 点击「加载贴花图片…」，选择透明 PNG 等图片。模式默认是「曲面贴合」。
4. 需要跨过机身小缝或蒙皮边缘轻微穿插时，勾选模式下方「跨越微小缝隙」，默认允许2 mm，可拖动旁边数值或Ctrl+单击输入0.1–20 mm。经过机背直角或机翼锐边时，再勾选「沿锐边延伸」。两项默认都关闭。鼠标移到模型上，等待表面预览出现。`[` / `]` 改大小，`Q` / `E` 旋转，也可使用右侧滑块。
5. 左键单击盖印。软件自动找到跨越的材质与 UV，整次盖印可一步撤销。后台计算期间可以取消，失败也会恢复整次操作。
6. 使用「保存工程与 DCS 涂装」保存分层工程、合成 DDS 与 description.lua。通用模型导出使用可见图层的合成结果。

鼠标刚移动到新的落点时，较复杂的曲面需要短暂计算。此时直接单击也会按这个落点处理，不会丢掉点击。右键旋转、中键平移、滚轮缩放保持原操作。画面下方「浏览已编辑的涂装」取消勾选时，同时隐藏浮动贴花预览并暂停绘制输入。

## 两种贴花方式

| 模式 | 适合情况 | 范围控制 |
| --- | --- | --- |
| 曲面贴合 | 图案沿弯曲机身延伸、跨相连网格/材质接缝 | 相邻面折角、朝向、放置视角的遮挡 |
| 平面投射 | 较平坦区域、希望保持固定方向的印章效果 | 宽高、投射深度、朝向、平行投射遮挡 |

独立「相机投影」工具仍然保留，用于把当前视角中的整张图片映射到可见模型。

「贴合范围与遮挡」中的折角控制相邻三角面之间允许跨越的角度，默认65°。点击开启「沿锐边延伸」将它设为135°，关闭恢复65°；详细滑块可调10–150°。减小它可阻止图案绕过锐利边缘。曲面模式不会因为旧投射盒的深度限制而在弯曲处截断。启用遮挡时，使用放置瞬间的视角；仅旋转观察视角不会改变预览落点和贴合坐标。

## 为什么20 mm仍可能过不去

缝宽控制距离，折角控制转向，二者各自生效。FA-18C边条平台接机背的位置，平台边缘轻微穿入侧壁三角面内部，旧版仅查找“边接边”，增大缝宽也不能找到它。0.12.1加入这种“边接面”的连接，并裁掉侧壁位于平台内部的一侧，避免图案沿内部蒙皮继续传播。该处转角约87°，需要同时开启「沿锐边延伸」。外缘另有约123°的原生折返边，同样需要提高折角上限。

在截图位置可以先用「跨越微小缝隙」2 mm加「沿锐边延伸」检查预览；不同落点仍可能需要调整缝宽。20 mm并不能越过任意结构。图片本身的透明留白、背面或遮挡、目标UV边界以及无法一致展开的区域，也会留下空白。

## 保留的模型关系

运行时只建立局部表面连接和贴花坐标，原始网格、材质、UV、节点和动画均保留，导出也使用原结构。边缘位置吻合且方向合理时可跨网格/材质接缝。启用跨缝时，距离内相对的边界条带可形成临时连接，支持一条长边对应几条短边。图案坐标保留缺失条带的物理距离，不会把缝压成零宽、拉伸邻面或在另一侧重新开始。没有几何的缝中不产生绘画像素，也不会补洞。

距离小只是条件之一：还检查边界投影重叠、相对方向、局部切面和所属外挂实例。边接边的小缝仍采用不超过30°的局部方向限制，拒绝明显台阶；新增的边接面接触和原生连续网格采用用户的折角上限。接触线两侧保留实际距离与原始三角形UV，只允许进入外露部分；平行叠层、歧义邻居、反面和不同外挂实例不会成为这类连接。这是保守的几何判断，不是对飞机机械部件的语义识别；相邻独立部件之间若也满足这些条件，绘制前需检查预览。可以直接将鼠标移到可见外挂上绘制。

隐藏外挂会从绘画拾取、曲面连接与遮挡中排除。独立碰撞壳没有 UV，不能作为贴花目标。新增的绘画连接数据不代表新增了完整的部件浏览或部件隔离界面。

## 清晰度与适用范围

首次绘制默认保留原始贴图尺寸，最高8192，小图不放大；也可选择4096/2048上限来节省内存。展开「落点清晰度」查看画布尺寸和局部可用像素估计。旧工程中已经降到2K的像素不会自动恢复，需从原涂装重新绘制；小贴花仍受目标UV区域像素数限制。

- 跨缝关闭时保持原来的严格连续方式；开启后支持限定距离内的细小间隙、不同细分的边界和不同网格间的局部边到面接触。当前每条传播分支只跨一次边到面接触，之后仍可沿原生相连面延伸；连续多层穿插结构可能停止。超过缝宽、明显台阶、非流形重叠边和不确定的连接仍会停止。
- 双向弯曲的曲面无法无失真展开到平面；这一版限制局部拉伸，无法一致展开的区域会停止。图案很大时可缩小后分次盖印，或切换平面/相机投影。
- 原始 UV 共用或重叠时，同一像素仍会联动。不会重排 UV 或修改 DCS 材质格式；UV 岛边缘的像素密度和纹理过滤仍可能影响接缝效果。
- 预览使用 GPU 表面坐标和有限分辨率的遮挡深度图，最终绘制使用精确射线；细小遮挡边缘和纹理过滤可能有差异。
- 盖印后是当前图层中的像素，尚不是可以再次拖动的独立贴花对象；需要调整时撤销再盖印。

没有新增第三方运行库，不修改 DCS 游戏文件。
