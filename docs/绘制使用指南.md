# 在 EDM Studio 0.11.0 中制作涂装

0.11.0 的贴花默认使用「曲面贴合」，可沿相连表面延伸并跨越网格/材质接缝；「平面投射」仍可切换。具体步骤和第一版的范围见[曲面贴花说明](SURFACE_CONFORMING_DECALS.md)。绘制工具均写入当前涂装图层，图层管理及工程保存见[图层说明](PAINT_LAYERS.md)。

## 开始绘制

打开模型，在“涂装”页选好基础涂装，并调节动画到适合绘制的姿态。进入“绘制”后即可使用“浏览 / 直接画笔 / 贴花 / 相机投影”；不需要先拾取材质或手动创建画布。

软件根据实际落笔位置或图片覆盖范围自动匹配漫反射贴图。新画布分辨率上限默认2K，可以切换到4K或8K；此设置只影响之后建立的画布，已有画布不会被重新缩放。单张画布最大边长8192，全部画布受像素内存预算约束。

编辑的是漫反射颜色。RoughMet、法线等基础资源在保存完整DCS涂装时一并保留；动态编号图集不参与绘画，编号仍在原编号面板设置。

“涂装 → 贴图质量”中的预览贴图预算默认 2 GB，可手动输入 0.25–100 GB，回车或点击“应用贴图预算”生效并保存。预算按 1024³ 字节/GB 计算，是基础预览贴图的加载上限，不会预先分配整个预算，也不会改变绘制画布大小或导出分辨率。

## 直接画笔

模型画面下方的“浏览已编辑的涂装”默认勾选。取消勾选可对照编辑前的基础涂装；重新勾选恢复绘制效果。比较时不重载模型或贴图，编辑内容与撤销记录保留，保存和导出仍包含已编辑的结果。未编辑视图中暂停新的画笔、贴花与投影操作，已有后台操作继续完成。

从此版本保存的完整工程会额外保留原始颜色贴图，因此重开工程也能对照编辑前后。旧版工程没有保存原图，无法从已经烘焙的成品恢复更早的外观；载入时会提示，仍可比较本次打开后新增的编辑。

选择“直接画笔”，设置颜色、世界半径、硬度和不透明度，在模型上按住左键绘制。软件自动找到落笔表面使用的漫反射贴图，必要时在后台读取贴图并建立画布。笔迹会跨UV接缝和材质边界，无需松开鼠标后重新选择部件。

贴图尚在加载时，鼠标轨迹会进入队列。松开鼠标后，等待尚未处理的笔迹完成；一次按下到松开仍算一笔，撤销或重做会同时处理这一笔涉及的所有贴图。取消或失败时，整笔回滚。

右键旋转视角，中键平移，滚轮缩放。遮挡筛选可以防止笔刷穿透被挡住的表面；保留原透明度可保护已有材质遮罩。调节动画后，软件在后台重建当前姿态的拾取结构；普通视角移动复用结构和GPU模型。

## 载入涂装模板

先加载平面模板，再在目标部件上落笔。下一次落笔位置决定模板绑定到哪张漫反射贴图；模板替换该贴图的当前图层内容，然后继续进行绘制。原始底图和其他图层保留，整次操作可撤销；取消加载或绘制时恢复原有内容。

模板支持PNG、DDS、TGA、JPG等格式。PSD图层需先导出平面PNG。模板不是局部贴花：只想添加一个标志或一张局部图片时，使用下面的贴花或相机投影。

## 贴花：加载图片的画笔

选择“贴花”，点击“加载贴花图片”，推荐带透明背景的PNG。把鼠标移到飞机表面，图片会沿落点表面的朝向贴合预览；左键单击即可盖印，软件自动把图案写入覆盖到的漫反射贴图，不需要选材质或创建画布。每次单击盖一次，按住左键不会连续重复叠加。

- 宽度决定贴花在模型上的实际大小（米），默认锁定图片长宽比。
- 调整旋转与不透明度；鼠标在视口内时，`[` / `]` 缩小、放大，`Q` / `E` 每次旋转5度。
- 鼠标移到右侧调整参数时保留最后有效落点，可以点击“在当前落点盖印”。移出模型到空白处则清除落点。
- 右键旋转模型，中键平移，滚轮缩放视角；相机移动不改变已盖印图案。

预览直接显示在三维模型表面，尚未盖印时不会建立画布或修改贴图。盖印后暂时隐藏当前位置的预览，以便检查真实结果；移动鼠标后继续预览下一次盖印。取消“显示表面预览”也可以随时检查已经写入的贴图。

模式默认为「曲面贴合」，沿相连三角面延伸；「贴合范围与遮挡」可设置允许跨越的折角，按放置时视角剔除背面与遮挡。「平面投射」保留旧投射方式，在同一区域调整前后的投射厚度。预览使用 GPU 深度图，极细遮挡边缘可能有像素级差异，最终写入使用逐纹素射线判断。

一次盖印可跨UV接缝和多张贴图，整次应用只有一个撤销步骤。贴图首次读取与盖印在后台进行，完成后自动更新；取消或失败时回滚本次全部修改。贴花记录采用普通涂装像素，保存、工程重开和GLB导出流程相同。

## 当前摄像机投影

选择“相机投影”并加载图案，将模型旋转到需要的视角。视口中的半透明图案表示投影范围，可以调整中心、尺寸和旋转；锁定长宽比可避免图案被拉伸。

应用时固定这一刻的摄像机、图片位置和模型姿态，自动把图案写入覆盖到的全部漫反射贴图。图案跨越材质边界时，一次应用即可。运算期间移动相机不会改变已经提交的投影位置。

默认仅处理朝向相机且未被其他几何遮挡的表面；可以调整背面、遮挡及保留透明度选项。处理完成后关闭预览蒙层，再自由转动模型检查表面上的实际结果。投影与贴花一样支持跨贴图统一撤销、重做及取消回滚。

高精度、整机范围的图片可能触发运算保护（2K及以上为300秒，较低精度为120秒），此时整次回滚。请缩小图片覆盖范围，或在开始编辑新画布前降低精度；改变精度不会缩小已经编辑的画布。大笔刷碰到非常密集的表面时，也可能提示采样范围过大，缩小笔刷后重新绘制即可。

## 保存、恢复与模型导出

- “保存工程与DCS涂装”：在选择的目录中新建完整文件夹，包含所有已编辑贴图的PNG、带mip的DDS、基础资源、`description.lua`和工程清单。把完整文件夹放到正确机型的`Liveries`目录中使用。
- “打开绘制工程”：加载之前保存的工程或恢复工程，校验模型、UV与材质身份，并恢复基础涂装、外观参数和绘制内容。
- GLB / glTF导出：右侧“导出”页输出当前绘制结果，动画选项仍可使用。预览贴图质量限制不会额外降低导出贴图分辨率；已编辑区域使用当前画布的实际分辨率，需要高分辨率绘制时应在首次落笔前选择4K或8K。
- 关闭或切换模型前，未保存编辑写入EXE旁的`PaintRecovery`。恢复保存失败时保留窗口及编辑。恢复工程用于重新打开继续编辑，之后仍需正式保存完整DCS涂装。

原始 EDM、基础贴图与载入模板不会被改写。完整涂装输出使用新目录，生成完毕才发布；保存取消不会把未完成文件夹当成有效涂装。

## 已知边界

共用或重叠UV会让多个表面一起改变，因为它们引用同一纹素。软件会合并同名且引用相同漫反射资源的材质别名，避免一次图片应用在同一画布上重复叠加透明度；这不会让共享UV的部件获得独立颜色。

候选覆盖判断保留可能可见的细小部件，真正遮挡在逐纹素写入时检查。完全被挡住或没有产生像素变化的候选，不会以新建的低分辨率画布替换原贴图。几何遮挡暂不采样透明贴图孔洞，透明舱盖等几何仍可能挡住后方投影。

DCS按材质名称绑定贴图。如果导入的工程为无法区分的同名材质提供不同图片，完整涂装保存会报告冲突；恢复工程仍保留编辑内容。目前不提供PSD图层、任意曲面包裹变形或RoughMet通道绘画。
