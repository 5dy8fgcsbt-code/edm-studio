# 模型导出

右侧选择“导出”，在“文件格式”中选择 GLB、glTF、OBJ 或 FBX，然后点击导出按钮。保存窗口也可以切换格式。导出使用当前涂装、编号、动画参数和已绘制结果；预览贴图预算不会限制导出贴图分辨率。

| 格式 | 几何与动画 | 贴图与用途 |
|---|---|---|
| GLB / glTF 2.0 | 层级、8 权重蒙皮、每参数动画、STEP 显隐与编号 | 嵌入 PNG；RoughMet 转为标准 PBR；适合网页和现代工具 |
| OBJ + MTL | 当前姿态的世界坐标网格；不含骨骼或动画 | PNG 颜色、独立透明遮罩；适合静态建模与通用导入 |
| FBX 7.4 二进制 | 层级、8 权重蒙皮、独立动画片段、STEP 显隐与编号 | 嵌入 PNG；适合需要 FBX 动画的工具 |

## OBJ

先在预览中调整起落架、舵面、座舱盖等参数，再导出。隐藏部件会被排除，蒙皮网格会固定为当前变形。法线按变换修正；镜像变换会调整三角形顺序。

OBJ 文件旁会生成具有唯一名称的 `edm_obj_*.mtl` 和 `edm_obj_*` 贴图目录。必须将三者一起复制。名称使用 ASCII，避免部分 OBJ 读取器无法处理中文贴图路径。模型和用户选择的 OBJ 文件名仍可使用中文。导出报告位于这个新贴图目录中的 `report.json`。重复导出会保留旧的附属目录，防止破坏仍引用旧贴图的文件；确认无需旧版本后可手动删除旧目录和对应 MTL。

OBJ 保存当前编号图集的 UV 与透明遮罩。MTL 不会复现 RoughMet 和 DCS 专用着色器效果。

## FBX

选择“全部参数动画”或“仅当前参数动画”。每个参数对应一个 `Argument 000` 形式的动画片段；原参数最小值到最大值映射到所设时长，其他参数固定为导出时的当前值。也可以选择“当前姿态（静态）”。在目标软件中选择对应的动画片段播放，避免混合互相独立的参数片段。

Blender 会将一个 FBX 片段拆成多个对象/骨架的 Action，名称带相同的 `Argument NNN` 后缀。切换参数片段时，需要给相关对象/骨架选择同一后缀的动作。大型模型建议先导出需要的参数，缩短目标软件的导入时间。

FBX 使用右手 Y 向上坐标、米单位，文件单位声明为每单位 100 厘米。旋转从四元数采样为连续欧拉曲线，并自适应细分；显隐和编号使用恒定插值，避免部件在切换时缓慢缩放。

Blender 4.2 的 FBX 导入器忽略恒定插值标记，并合并过近的关键帧。导出额外添加保持帧，把普通切换的兼容过渡限制到约 0.46 毫秒；极短显隐脉冲仍可能被该导入器丢弃。遵循 FBX 恒定插值的读取器保留原 STEP 行为，已用 ufbx 验证。对显隐边界要求严格时，优先使用 GLB 或确认接收软件支持 FBX CONSTANT 插值。

PNG 已嵌入 FBX。接收软件可能将贴图提取到 FBX 旁的目录。颜色与透明度连接到通用材质；RoughMet 以显式 `EDM_ORMImage` 资源保留，可能需要在目标软件中自行拆分 R/G/B 为环境遮蔽/粗糙度/金属度。透明裁切、双面显示和 DCS 专用效果的表现取决于目标软件。动态 Lua 已在导出前求值，文件中不运行 DCS Lua。

当前 FBX 7.4 写入器使用 32 位文件偏移，超过 4 GB 会明确报错并保留原文件。大文件可减少导出参数、关闭贴图或拆分模型后再导出。程序直接用 C++ 写入 FBX，不需要 Autodesk SDK、Blender、Python 或外部转换进程。

## 命令行

输出文件扩展名决定格式：

```powershell
./edm-native-cli.exe export 'aircraft.edm' --output 'aircraft.fbx' --args 0,9,10,38 --duration 3
./edm-native-cli.exe export 'aircraft.edm' --output 'aircraft.obj' --baseline 0=1,38=1
./edm-native-cli.exe export 'aircraft.edm' --output 'static.fbx' --static --livery 'Livery/description.lua'
```

OBJ 始终是静态导出，`--args` 不会生成动画。原有 `--livery`、`--context`、`--baseline`、`--bort` 和 `--no-textures` 同样适用。CLI 将导出报告输出为 JSON。
