# 模型导出

右侧选择“导出”，在“文件格式”中选择 GLB、glTF、OBJ 或 FBX，然后点击导出按钮。保存窗口也可以切换格式。导出使用当前涂装、编号、动画参数和已绘制结果；预览贴图预算不会限制导出贴图分辨率。

已连接的外挂会与主模型一起导出。普通模式包含 Pylon / Point 层级及各自动画，开启贴图导出时还会生成独立涂装目录，统一保存 description.lua、DDS 与 RoughMet。纯网格模式只保留外挂的实际几何与贴图，不生成挂点节点或涂装配置。下方的“显示外挂物体”仅影响预览和绘制遮挡；导出保留整个组合。详见[挂接与涂装](ATTACHMENTS.md)。

从 0.12.4 起，内部 LOD 自动按距离范围选择最高精度分支。多个或嵌套 LOD 组独立处理，外挂同样适用。预览、绘制和导出使用相同选择，低精度模型不会再叠在一起；原始网格编号、UV 和材质保持不变，已保存的涂装工程可以继续加载。此选择自动生效，无需手动删除 LOD。

| 格式 | 几何与动画 | 贴图与用途 |
|---|---|---|
| GLB / glTF 2.0 | 层级、8 权重蒙皮、每参数动画、STEP 显隐与编号 | 嵌入 PNG；RoughMet 转为标准 PBR；适合网页和现代工具 |
| OBJ + MTL | 当前姿态的世界坐标网格；不含骨骼或动画 | PNG 颜色、独立透明遮罩；适合静态建模与通用导入 |
| FBX 7.4 二进制 | 层级、8 权重蒙皮、独立动画片段、STEP 显隐与编号 | 嵌入 PNG；适合需要 FBX 动画的工具 |

## 只导出模型（纯网格）

若用 Substance 3D Painter 绘制原 DCS 涂装，通常应在新建项目中取消 `Use UV Tile workflow`，保留原 UV，不要重新展开全部 UV。部分源模型会重复使用或越出 0–1 UV 范围，并不等同于 UDIM 布局；跨 UV 格子的面在 UDIM 导入时可能报错。LOD 修复排除了 AIM-9 低精度分支中的这类面，但不会自动改写其他模型原有的 UV。参考 [Adobe 项目创建](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/getting-started/project-creation)及[相同报错的官方支持回复](https://community.adobe.com/questions-59/substance-3d-painter-won-t-load-my-3d-models-627830)。本机没有 Painter，兼容性结论以实际验证的软件与样本为限。

先在预览中调整起落架、舵面、舱盖等参数，在右侧「导出」勾选「只导出模型（纯网格）」，再点击「导出纯模型」。所有参数组合与蒙皮变形都固定到顶点，当前编号固定到 UV；默认文件名加 `_model`。导入 Blender 后只有网格物体，不再出现 Armature、空物体、骨骼锥体或父子辅助线。

勾选后，动画范围和时长不可用；取消勾选恢复动画导出。这个选项会自动记住，顶部按钮和 Ctrl+E 使用相同设置。点击导出、打开保存窗口时即固定参数，之后继续播放或修改参数不会改变这次导出的姿态；在保存窗口切换文件格式也不会使静态导出变为动画导出。

保留实际网格分件、当前世界位置、法线、有效 UV、必要材质和贴图。完整父级矩阵直接参与顶点烘焙，保留剪切与镜像效果，无需在目标软件中解除父级。移除动画、骨骼、蒙皮权重、挂点、空节点、DCS 自定义元数据及不再引用的缓冲、材质和图片。当前姿态下被显隐缩放压为零面积的三角形会排除；不合并原来的分件。整个组合中已连接外挂的可见几何也会烘焙。

「导出贴图与当前涂装」可独立勾选，保留当前涂装与可见绘制图层的合成图。GLB/glTF/FBX 使用文件内嵌 PNG；OBJ 需要旁置 MTL 与 PNG。纯模式不生成 description.lua、DDS 涂装包或 JSON 报告旁文件，也不会主动删除以前导出留下的文件。材质槽与格式要求的坐标/单位信息属于模型正常显示所需内容。

0.12.2 的同类选项只移除动画，仍保留骨架；0.12.3 开始 GUI 选项改为上述纯网格语义。命令行 `--model-only` 对应新模式；原 `--static` 保留旧的无动画但带层级/蒙皮模式。

## OBJ

先在预览中调整起落架、舵面、座舱盖等参数，再导出。被模型动画隐藏的部件会被排除，蒙皮网格会固定为当前变形。法线按变换修正；镜像变换会调整三角形顺序。“显示外挂物体”预览开关不影响导出。

OBJ 文件旁会生成具有唯一名称的 `edm_obj_*.mtl` 和 `edm_obj_*` 贴图目录。必须将模型、MTL 和所需图片一起复制。名称使用 ASCII，避免部分 OBJ 读取器无法处理中文贴图路径。模型和用户选择的 OBJ 文件名仍可使用中文。GUI 的纯模式不生成报告，没有图片时不保留空贴图目录；CLI 的普通模式仍将 `report.json` 写入这个目录。重复导出会保留旧的附属目录，防止破坏仍引用旧贴图的文件。

OBJ 保存当前编号图集的 UV 与透明遮罩。MTL 不会复现 RoughMet 和 DCS 专用着色器效果。

## FBX

不透明材质使用无 Alpha 的 RGB PNG，防止部分导入器自动连接图片 Alpha 而隐藏模型。普通模式同时嵌入原始 RGBA 图片并用 `EDM_OriginalDiffuseImage` / `EDM_OriginalImage` 保留来源关系。纯模式不附加这些元数据，也不重复嵌入无用途的原图；透明材质和编号继续使用原始 Alpha。

取消勾选“只导出模型（纯网格）”，选择“全部参数动画”或“仅当前参数动画”。每个参数对应一个 `Argument 000` 形式的动画片段；原参数最小值到最大值映射到所设时长，其他参数固定为导出时的当前值。在目标软件中选择对应的动画片段播放，避免混合互相独立的参数片段。

Blender 会将一个 FBX 片段拆成多个对象/骨架的 Action，名称带相同的 `Argument NNN` 后缀。切换参数片段时，需要给相关对象/骨架选择同一后缀的动作。大型模型建议先导出需要的参数，缩短目标软件的导入时间。

FBX 使用右手 Y 向上坐标、米单位，文件单位声明为每单位 100 厘米。旋转从四元数采样为连续欧拉曲线，并自适应细分；显隐和编号使用恒定插值，避免部件在切换时缓慢缩放。

Blender 4.2 的 FBX 导入器忽略恒定插值标记，并合并过近的关键帧。导出额外添加保持帧，把普通切换的兼容过渡限制到约 0.46 毫秒；极短显隐脉冲仍可能被该导入器丢弃。遵循 FBX 恒定插值的读取器保留原 STEP 行为，已用 ufbx 验证。对显隐边界要求严格时，优先使用 GLB 或确认接收软件支持 FBX CONSTANT 插值。

PNG 已嵌入 FBX。接收软件可能将贴图提取到 FBX 旁的目录。颜色与透明度连接到通用材质；普通模式用 `EDM_ORMImage` 标识 RoughMet，纯模式则保留名为 `image_N_RoughMet.png` 的嵌入图片，不附加自定义属性。RoughMet 需要在目标软件中自行拆分 R/G/B 为环境遮蔽/粗糙度/金属度。透明裁切、双面显示和 DCS 专用效果的表现取决于目标软件。动态 Lua 已在导出前求值，文件中不运行 DCS Lua。

当前 FBX 7.4 写入器使用 32 位文件偏移，超过 4 GB 会明确报错并保留原文件。大文件可减少导出参数、关闭贴图或拆分模型后再导出。程序直接用 C++ 写入 FBX，不需要 Autodesk SDK、Blender、Python 或外部转换进程。

## 命令行

输出文件扩展名决定格式：

```powershell
./edm-native-cli.exe export 'aircraft.edm' --output 'aircraft.fbx' --args 0,9,10,38 --duration 3
./edm-native-cli.exe export 'aircraft.edm' --output 'aircraft.obj' --baseline 0=1,38=1
./edm-native-cli.exe export 'aircraft.edm' --output 'static.fbx' --static --baseline '0=0.8,9=0.6,10=0.4,38=1' --livery 'Livery/description.lua'
./edm-native-cli.exe export 'aircraft.edm' --output 'aircraft_model.fbx' --model-only --baseline '0=0.8,9=0.6,10=0.4,38=1'
```

OBJ 始终是静态导出，`--args` 不会生成动画。原有 `--livery`、`--context`、`--baseline`、`--bort` 和 `--no-textures` 同样适用。CLI 将导出报告输出为 JSON。
